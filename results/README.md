# Results

The project uses two evaluation views:

1. A common 10,000-row validation subset for comparing all experimental configurations.
2. The complete 52,121-row validation split for the final Random Forest vs CatBoost confirmation.

Final candidate model: CatBoost (Geographic Categorical)

Full validation results:
- Accuracy: 74.67%
- Macro F1: 0.6934
- Weighted F1: 0.7414
